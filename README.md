# V.A.C. Breaker Panel

A practice simulator for Blue Prince's Utility Closet V.A.C. breaker puzzle. Reset it and drill the sequence as many times as you want — no need to keep reloading the actual game.

Open `index.html` in any browser, or serve the folder statically (e.g. GitHub Pages).

Controls:
- Click a light to cycle it, or use **A**/**D** to move between lights, **W**/**S** to reach the controls, and **Enter** to activate.
- **Reset** returns every light to off. **Undo** steps back one click.
- **Solution** reveals a step-by-step cheat sheet.
